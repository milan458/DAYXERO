# DayXero App Store listings

One folder per App Store Connect locale, in the layout fastlane `deliver` and the App Store Connect API expect:
`name.txt` (30), `subtitle.txt` (30), `keywords.txt` (100), `promotional_text.txt` (170) and `description.txt` (4000), plus `privacy_url.txt` and `support_url.txt`.
`screenshot-captions.json` holds the caption text for the 20 Nov screenshot set (direction E, "Meet the crew"), frame by frame.

The app itself stays in English for now, so every non-English description says so. Drafts for Milan's review: nothing
here has been uploaded to App Store Connect. The subscription paragraph names no prices or trial length until the
pricing is settled.

Locales at launch: en-US, en-GB, en-CA, en-AU, de-DE, fr-FR, es-ES, es-MX, pt-BR, it, nl-NL, sv.
