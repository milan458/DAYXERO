DayXero design system

Tokens and core components from DESIGN_METHODOLOGY.md, ready to become DesignSystem/ in SwiftUI. Use Theme to switch every component between dark and light. Tabs, chips, the slider and the list row are interactive.

Colour

Contrast changes (proposed). The methodology's muted text at 35% white on black measures about 3.0:1, below WCAG AA (4.5:1) for small text. I've raised muted text to 50% (≈5.3:1), and upcoming-day numerals from #555555 to the muted token. White text on terracotta (#C85A54) is about 4.2:1, so it's used only at 15pt semibold or larger, or on icons.

Type

Each style maps to a Dynamic Type text style so it scales with the user's text size. Use the typeface toggle to compare Inter with SF Pro.
