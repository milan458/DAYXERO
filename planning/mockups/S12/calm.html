Calm tools

Five short, practical exercises for the moments people reach for nicotine to cope with stress. One to three minutes each, no accounts, no scores. It's not a mental-health app: no diagnosis, no clinical claims, and a plain line pointing to professional help. Reachable from Craving SOS and the Program tab.

Not shown as screens

The five tools. Box breathing (2 min) · Longer out-breath (2 min) · 5-4-3-2-1 grounding (2 min) · Notice and name (1 min, ACT-style) · Drop anchor (1 min, ACT-style: feel your feet, notice the room, come back to what you're doing). Descriptions say what you do, not what it treats.

Haptics and accessibility. Breathing tools use the same gentle pulse as Craving SOS; Reduce Motion keeps shapes still and changes only the words. VoiceOver reads each cue. Every tool can be stopped at any time.

Logging. Using a tool is counted (which one, when, and the "a bit calmer?" answer if given) so Insights can show which ones you come back to. Nothing is required.
