# DayXero

A native iOS (SwiftUI) quit program for nicotine: cigarettes, vapes and pouches, with NRT support.

- Build plan: [`docs/DAYXERO_V1_HANDOFF.md`](docs/DAYXERO_V1_HANDOFF.md)
- Design system: [`design/handoff/DAYXERO_DESIGN_SYSTEM.md`](design/handoff/DAYXERO_DESIGN_SYSTEM.md) and `design/handoff/tokens.json` (v4, decision 14). The old [`docs/DESIGN_METHODOLOGY.md`](docs/DESIGN_METHODOLOGY.md) is superseded and kept for history only.
- Task tracker: `npm run tracker` → http://localhost:4321 (see [`planning/README.md`](planning/README.md))
- Website: [`website/`](website/) is served at https://dayxero.in by the `dayxero` Cloudflare Worker, which also runs the beta waitlist API ([`website/worker/`](website/worker/README.md)); the `Website` workflow deploys it on every push to `main` that touches `website/`. Guide pages, the About, Contact, Privacy and Terms pages, and `sitemap.xml` are generated by `npm run website:guides` (edit `scripts/website/build_guides.py`), and the CSS by `npm run website:css`
