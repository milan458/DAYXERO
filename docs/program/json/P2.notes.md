## Copy decisions

- "A short wait", never "gap", for the morning delay: the `morning_anchor` prompt is now "Which moment will you wait after?"; `completionText` is now "Tomorrow morning: one small wait. That's all." (the draft's proposed change, per README "Decided"); the mission says "take your short wait". "The gap" is used only for the feeling between doses.
- The old P2.3 quiz and the 90-second `cards` stack (incl. "What's a gap?") are dropped.
- Session `title`/`subtitle` kept ("The first one of the day" / "Loosen the morning routine").
