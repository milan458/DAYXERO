4. **Body map (Screen 3)** → multi `choice` (P5.3b) with the five zones and two chips as seven options (the draft's own fallback). Closer alternative if wanted: a `note` beat (`title` "I'm having the thought that…", `textFrom: control_thought`) just before it, which would show the person's own words.

10. **Phase words on the ring** ("In · Hold · Out · Rest") and the "Done" button: not settable on `breathe`; the orb's own labels apply. `pattern: wave`, `cycles: 4` (14 s a cycle = 56 s).
