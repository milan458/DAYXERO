## Copy decisions

- "Battery" is gone: the old P1 quiz (`P1.4`) and its "That's the battery" feedback are dropped (the Reveal and Myth cards replace it); the mission now reads "…ask: how much of this is the gap?".
- Money reveal: the old `P1.1` `stat_reveal` lines are in `recap.statLines`, unchanged.
- Old 90-second `cards` stack removed (deck session).
- `completionText` kept as is.
