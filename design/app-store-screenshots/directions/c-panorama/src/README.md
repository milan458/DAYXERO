# Direction C source

This folder renders Direction C, "The sky clears": one continuous panorama across all ten frames. See `../README.md` for the frame table, the checks and how to re-render.

The quick version:

```
node render.mjs    # renders the frames, both sizes, and the contact sheets
node check.mjs     # checks the seams and the caption contrast
```

`app/` and `fonts/` are unchanged copies from Direction A (`design/app-store-screenshots/src/`).
