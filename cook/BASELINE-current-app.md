- Home leads with a green paywall 'Unlock'; paywall appears twice in a row (B01 then B02).
- Program path labels collide with the road and each other (B05, B07); 'Next up' card is stale on other tabs.
- Lesson controls: C03 says tap to flip but answers already show; Myth/Fact use navigation chevrons; C10 repeats the Quit Day hold; empty half-screens on C05/C07/C09/C10.
